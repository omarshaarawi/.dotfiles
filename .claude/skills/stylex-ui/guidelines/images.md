# Images

Covers: photos, thumbnails, screenshots, app mockups, product images, media frames, and image borders/outlines.

## Design Rules

- Never put a border on a photo or thumbnail. If it needs a visible edge, use a `1px`
  outline at 5–10% black with a `-1px` offset so the line sits inside the image rather
  than adding to its box
- Use black at 5–10% on light surfaces and white at 10% on dark surfaces, for screenshots
  and app UI mockups alike

## Coding Rules

- Use `alt=""` when the subject is identified by adjacent visible text
- See [Border Radius](./border-radius.md) for screenshot radii
