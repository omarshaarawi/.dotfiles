# Description Lists

Covers: `<dl>`, `<dt>`, and `<dd>` content, term/detail pairs, metadata groups, and definition-style lists.

- Style `<dt>` with a higher contrast color and a slightly heavier weight
  (`fontWeight.medium`); style `<dd>` with regular weight and a lower contrast color. This
  leaves the higher contrast color free for links inside `<dd>` to stand out against
