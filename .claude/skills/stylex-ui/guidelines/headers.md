# Headers

Covers: site headers, navigation bars, top bars, logos, mobile menus, hamburger menus, and header CTAs.

- Always wrap the main logo in an `<a href="/">` with `aria-label="Homepage"`
- A navbar button must always feel secondary to the hero's primary CTA. Use ghost, outline,
  subtle, or a noticeably smaller solid button. Matching the hero's color is fine only if
  the navbar button is clearly smaller
