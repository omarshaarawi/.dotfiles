# Login Pages

Covers: login, sign-in, sign-up, authentication, password reset, and account access pages.

- Never use a light gray or other light-tinted page background on login/sign-in pages
  (`zinc[50]`, `zinc[100]`) — use solid white or a true dark (`zinc[900]`, `zinc[950]`,
  `base.black`), unless the form content is wrapped in a distinct panel or card
